# Lebanon Live Activity Map

Live map of reported aerial and artillery strike locations in Lebanon, with distances from Beirut–Rafic Hariri International Airport (BEY).

- `index.html` — the site (satellite map + interactive side panel). Checks `data.json` for new reports every minute.
- `data.json` — reported events. Updated hourly from news reports.

Locations are approximate and based on public reports. This is not an official warning system; follow official and embassy alerts.
